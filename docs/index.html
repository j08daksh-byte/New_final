Critical Limitation Found: The model architecture is highly specialized for single-operation environments. Using 20-cycle rolling means destroys predictive signal in FD002/FD004 because it averages across varying altitudes and throttles. Data access constraints in the sandbox prevented empirical testing, but the mathematical limits of the preprocessing pipeline are clear.
